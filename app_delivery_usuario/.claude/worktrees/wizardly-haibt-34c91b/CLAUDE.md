## Architecture

**DeliPuno** is a Flutter delivery app (portrait-only, Material 3) with no state management library — all state is local `StatefulWidget` or `setState`. Backend is Firebase (Auth + Firestore).

### Entry point & routing

`lib/main.dart` initializes Firebase via `firebase_options.dart` and registers all named routes on `MaterialApp`. Navigation is done via `Navigator.pushNamed(context, '/route')`. The main authenticated shell is `/home` → `MainShell`.

### Screen flow

```
/ (SplashScreen)
  → /login → /register → /verify
  → /home (MainShell — bottom nav)
       ├─ HomeScreen
       ├─ SearchScreen
       ├─ HistoryScreen
       └─ ProfileScreen
  → /store → /product → /cart → /address → /summary → /payment → /confirmed → /tracking → /rating
```

`MainShell` (`lib/screens/main_shell.dart`) holds the four bottom-tab screens in an `IndexedStack`.

### Theming

All colors are in `lib/theme.dart` as `AppColors` static constants. The global theme (`buildTheme()`) uses Plus Jakarta Sans via `google_fonts`. Key colors:

| Token | Hex | Usage |
|---|---|---|
| `primary` | `#FF6B35` | CTAs, active states |
| `secondary` | `#06A77D` | Confirmations, badges |
| `appText` | `#1A1A1F` | Body text |
| `bg` | `#F7F7F5` | Scaffold background |

### Shared widgets (`lib/widgets.dart`)

All reusable components live in a single file:

- `ImgPlaceholder` — striped diagonal placeholder for product/store images; accepts a `tone` (`warm`, `cool`, `green`, `purple`, `neutral`)
- `AppButton` — full-width button with `variant`: `primary`, `secondary`, `ghost`, `dark`, `soft`
- `AppInputField` — static display field (label + icon + value); not a `TextField`
- `DeliPunoLogo` / `DeliPunoWordmark` — brand identity widgets
- `StarRow` — 1–5 star display widget
- `SectionTitle` — heading row with optional action link

### Models (`lib/models/`)

Plain Dart classes with `fromMap` / `toMap` for Firestore serialization:

| File | Class(es) | Key fields |
|---|---|---|
| `user_model.dart` | `UserModel` | uid, name, email, phone, memberSince, totalOrders, totalSpent, rating |
| `store_model.dart` | `StoreModel` | id, name, category, categorySlug, rating, deliveryTime, deliveryFee, isOpen, tone, promo |
| `product_model.dart` | `ProductModel`, `ProductVariant`, `ProductExtra` | id, storeId, name, price, tone, badge, category, sizes, extras, isAvailable |
| `order_model.dart` | `OrderModel`, `OrderItem` | id, userId, storeId, items, subtotal, deliveryFee, total, status, address, paymentMethod |
| `address_model.dart` | `AddressModel` | id, label, street, reference, isDefault |

`OrderModel.statusLabel` maps status strings (`pending`, `confirmed`, `preparing`, `en_camino`, `entregado`, `cancelado`) to display text.

### Services (`lib/services/`)

All services use static methods — no instantiation required.

- **`AuthService`** — wraps `firebase_auth`: `signIn`, `signUp`, `signOut`, `sendPasswordReset`. Exposes `currentUser`, `currentUid`, `authStateChanges`.
- **`DbService`** — wraps `cloud_firestore`: CRUD for stores, products, orders, users, and addresses subcollection. `streamUserOrders` returns a real-time `Stream`.
- **`CartService`** — in-memory singleton (static fields): manages store context, line items (`CartEntry`), address selection, subtotal/total, and converts cart to `List<OrderItem>` for order creation.
- **`SeedService`** — auto-seeds Firestore with 6 stores and sample products on first run (`seedIfEmpty`). Safe to call on every launch.

### Assets (`lib/app_images.dart`)

`assetForKey(String key)` deterministically maps any string key to one of the local images in `images/`. Used by screens to pick a consistent placeholder image per store/product without storing image URLs in Firestore.

### Firebase setup

- `lib/firebase_options.dart` — generated by FlutterFire CLI; do not edit manually.
- `android/app/google-services.json` — Android Firebase config.
- `firebase.json` — Firebase project config.

### Dependencies

- `google_fonts: ^6.1.0` — Plus Jakarta Sans
- `cupertino_icons: ^1.0.8` — iOS-style icons (available but rarely used)
- `firebase_core: ^3.13.1` — Firebase initialization
- `firebase_auth: ^5.5.2` — Email/password authentication
- `cloud_firestore: ^5.6.6` — Firestore database
